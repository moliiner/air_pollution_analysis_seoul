# Data

Raw files are **not committed** (size and licence). Re-download them with `notebooks/00_data_acquisition.ipynb` and record each file below.

| Folder | Content | Edited? |
|---|---|---|
| `raw/` | Files exactly as downloaded | Never |
| `external/` | Reference data: weather (KMA), district boundaries (GeoJSON) | Never |
| `processed/` | Clean tables written by the notebooks (Parquet) | Only by code |

## Candidate sources (check the terms of use on each page before using them)

| Source | What it gives | Access |
|---|---|---|
| Seoul Open Data Plaza (data.seoul.go.kr) | Hourly / daily air pollutant measurements per district station | CSV download or Open API (key) |
| AirKorea via data.go.kr | National real-time and historical station measurements | Open API (service key) |
| KMA Open MET Data Portal (data.kma.go.kr) | Hourly weather: temperature, wind, rain, humidity | CSV download |
| Seoul district boundaries (GeoJSON) | Map of the 25 gu for choropleths | Public GeoJSON |
